# 게임 이벤트 일람

## 사용자와 목표
- 사용자 : 게임의 이벤트의 알림을 받으려는 사람
- 목표 : 사용자는 원하는 게임을 선택하여 해당 게임의 이벤트 정소를 받는다.

## 사용자의 흐름
1. 개인 정보 활용에 동의하고 알림을 받은 이메일을 작성한다.
2. 알림을 받을 게임의 이름을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 이벤트의 알림을 받을 시점을 선택한다.
4. 게임의 이름, 이벤트의 시점 설정을 확인하고 수정 하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터랙션 시나리오
1. 시작과 이메일 사용 안내
- 행동, 이벤트 : 기존 동의 체크박스를 선택하고 '알림 설정 하기'를 클릭한다.
- 조건 : 이메일 활용 동의가 선택되었는가?
- 반응, 다음 상태 : 동의 전에는 버튼을 누를 수 없다. 
동의 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다. 
팝업에서 '돌아가기'를 누르거나 ESC를 누르면 동의를 해재하고 시작 화면에 남는다. 
'동의하고 설정 시작하기'를 누르면 제목 입력 화면을 연다.

2. 게임 이름 입력
- 행동, 이벤트 : 게임 이름을 적고 '알림 설정하기'를 클릭한다.
- 조건 : 앞뒤 공백을 지운 이름이 비어 있는가?
- 반응, 다음상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 
값이 있으면 저장하고 조건 선택으로 이동한다.

3. 조건 선택
- 행동, 이벤트 : 알림을 받을 이벤트의 시점을 선택하고 '내용 확인하기'를 클릭한다.
- 조건 : 시점을 선택 했는가?
- 반응, 다음상태 : 선택했을 때만 시점을 보여준다

4. 내용 확인
- 행동, 이벤트 : 게임 이름, 시점을 읽고 수정하기 또는 설정 완료하기를 클릭한다.
- 조건 : 수정인가, 완료인가?
- 반응, 다음상태 : 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다. 
완료하면 완료 안내로 돌아간다.
``
5. 완료와 다시 설정
- 행동, 이벤트 : 완료 안내를 읽고 필요하면 다시 설정하기를 클릭한다.
- 반응, 다음상태 : 새 설정의 진행 상태를 초기화 하고 처음 부터 다시 시작한다. 
이미 확인 설정을 유지한다.
